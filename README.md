# Generacion de Imágenes con Deep Learning

## Tecnologias utilizadas
- Python
- PyTorch y Torchvision
- Hugging Face Diffusers
- PEFT y Accelerate
- Google Colab

## Implementaciones

**1. DCGAN – Fashion-MNIST**
- Preparación y procesamiento de imágenes.
- Implementación del generador y discriminador.
- Entrenamiento adversarial y generación de imágenes sintéticas.
- Visualización y análisis de resultados.

**2. Stable Diffusion + LoRA**
- Preparación del conjunto de imágenes.
- Carga de un modelo de difusión preentrenado.
- Ajuste fino mediante LoRA utilizando GPU.
- Generación y comparación de imágenes.

## Ejecucion
1. Abrir los notebooks `.ipynb` en Google Colab.
2. Activar GPU T4 para Stable Diffusion.
3. Ejecutar las celdas en orden.
4. Consultar los resultados y evidencias generadas.

## Objetivo
Comprender y aplicar técnicas de generación de imágenes mediante modelos generativos, analizando su funcionamiento, resultados y limitaciones computacionales.

## Documentación
El repositorio incluye los notebooks y el informe técnico con la metodología, explicación del código y análisis de resultados.
